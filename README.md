# The Missing Trace

A Capture the Flag challenge for CITM-501: Information Systems Infrastructure. Topic: real-time data integration and process optimization.

**Play the game:** [https://tulib199.github.io/missing-trace-ctf/](https://tulib199.github.io/missing-trace-ctf/)

Open that link in a browser. Enter a team name and start the incident. No login is required.

## For playtest teams

Use only the live game (or the player packet). Do not look for an answer key in this repository — it is not published here.

- Team of 3–4
- About 45 minutes
- Submit one flag: `FLAG{COMPONENT_HHMM_COUNT_OPTION}`
- 10 attempts; hints unlock at 15 and 30 minutes
